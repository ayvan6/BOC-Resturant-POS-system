# BOC Restaurant POS System

**BOC Restaurant POS System** is a professional Point of Sale application developed to streamline essential restaurant operations through an intuitive and efficient interface. The system is designed to support order processing, billing, menu management, and transaction handling while reducing manual effort and improving operational accuracy.

## Technology Stack

* **HTML** – Interface and web-based components
* **CSS** – Styling and presentation
* **Python** – Core application logic and functionality
* **Python Tkinter** – Graphical User Interface (GUI)
* **Shell Script** – Automation and Linux-based execution

## How to Run on Linux

Clone the repository:

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
cd <PROJECT-FOLDER>
```

Make the shell script executable:

```bash
chmod +x run.sh
```

Run the application:

```bash
./run.sh
```

### Alternative: Run Directly with Python

If the main application is a Python file:

```bash
python3 main.py
```

If Tkinter is not installed, install it using:

```bash
sudo apt update
sudo apt install python3-tk
```

> **Note:** Replace `run.sh`, `main.py`, and `<PROJECT-FOLDER>` with the actual filenames and folder name used in the repository.

## Project Overview

The BOC Restaurant POS System demonstrates the practical integration of **Python, Tkinter, HTML, CSS, and Shell Script** to create a functional restaurant management solution. The project is intended to provide a simple, efficient, and user-friendly platform for managing restaurant POS activities.
