# BOC Restaurant POS System

**BOC Restaurant POS System** is a professional restaurant Point of Sale application developed to streamline essential restaurant operations through an intuitive and efficient interface. The system is designed to support order processing, billing, menu management, and day-to-day transaction handling while reducing manual effort and improving operational accuracy.

### Technology Stack

* **HTML** – Interface and web-based components
* **CSS** – Styling and responsive presentation
* **Python** – Core application logic and functionality
* **Python Tkinter** – Graphical User Interface (GUI)
* **Shell Script** – Automation and system-level operations

The project demonstrates the integration of multiple technologies to develop a practical, user-friendly, and efficient POS solution for restaurant environments.
